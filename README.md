# Chinese Word Lists

Year 9 Chinese vocabulary lists with flashcard study and progress tracking.

- `index.html` – the app (lists, study cards, progress)
- `data.js` – word lists (characters, pinyin, English), oldest first
- `audio.js` – recorded pronunciation for each word

Results are stored in a separate database and are only reachable with the family code, which is not kept in this repository.
